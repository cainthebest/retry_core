## Installation

Add `retry_core` from [crates.io](https://crates.io/crates/retry_core) using Cargo:

```bash
cargo add retry_core
```

For prerelease versions, specify the version explicitly if required:

```bash
cargo add retry_core@1.0.0-beta.1
```
